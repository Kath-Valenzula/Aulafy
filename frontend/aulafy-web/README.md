# Aulafy Web

Aplicacion Angular del MVP Aulafy. Incluye login, layout protegido, rutas por rol, interceptor JWT y pantallas para muro, calendario, notas, asistencia, usuarios, cursos y notificaciones.

## Comandos

```bash
npm install
npm start
npm run build
npm run build:staging
```

La API esperada es `http://localhost:8080/api`, definida en `src/environments/environment.ts`.
El ambiente staging usa `src/environments/environment.staging.ts`.
