# Manual de usuario

## Ingreso

1. Abrir la URL del frontend.
2. Escribir correo y contrasena.
3. Presionar `Entrar`.

## Dashboard

Muestra accesos principales segun rol:

- Muro.
- Calendario.
- Notas.
- Asistencia.
- Usuarios y cursos para admin/colegio.
- Telegram para admin/colegio/profesor.

## Muro

- Seleccionar curso.
- Revisar publicaciones.
- Crear publicacion si el rol lo permite.
- Revisar si los comentarios estan abiertos o cerrados.

## Calendario

- Seleccionar curso.
- Revisar eventos ordenados por fecha.
- Crear evento si el rol lo permite.
- Activar Telegram solo si corresponde.

## Notas

- Buscar estudiante por ID demo.
- Revisar promedio parcial y mensaje explicativo.
- Crear evaluacion y registrar nota si el rol lo permite.

## Asistencia

- Buscar estudiante por ID demo.
- Revisar porcentaje y estado.
- Registrar asistencia si el rol lo permite.

## Telegram

Si Telegram no esta configurado, el sistema muestra resultado `NO_CONFIGURADO`. Esto es esperado en ambiente local sin secretos.
