1) Objetivo y alcance del sistema

Aulafy es una plataforma web para gestion escolar y comunicacion entre establecimiento, profesores, apoderados y estudiantes. El proyecto centraliza feed, calendario, notas, asistencia, anotaciones y chat interno, con dos experiencias: app familias/alumnos (mobile-first) y backoffice profesor/admin (desktop-first).

El alcance actual prioriza MVP funcional sobre arquitectura monolitica modular, manteniendo control por roles y pertenencia academica.

3) Avance backend (NestJS)

  • Seguridad: autenticacion JWT, RolesGuard, autorizacion por rol.
  • Acceso academico: reglas por pertenencia curso/alumno para profesor, apoderado y estudiante.
  • Modelo academico: levels, cycles, cycle_levels, students.
  • Modulos operativos: courses, academic, attendance, calendar, annotations, feed, notifications, chat.
  • Chat: salas por curso, mensajes persistidos, lectura y envio con permisos por pertenencia academica.
  • Telegram: envio manual y automatico con modo degradado (NOT_CONFIGURED) y bitacora.

4) Avance frontend (Angular)

  • Experiencia por rol en layout unico (familias/alumnos vs backoffice).
  • Vistas Stitch integradas y conectadas a API real.
  • Features funcionales: courses, academic, attendance, calendar, annotations, feed, notifications, messages, chat.
  • Guardias de autenticacion/autorizacion activos.
  • Servicios dedicados por dominio para desacoplar UI y transporte HTTP.

8) Decisiones tecnicas relevantes (ADR)

  • ADR-001: stack objetivo NestJS + Angular + MySQL + AWS.
  • ADR-004: monolito modular para MVP.
  • ADR-005: modelo academico base alineado a childsafe.
  • ADR-007: notificaciones con modo degradado y trazabilidad.
  • ADR-008: chat interno por salas de curso con permisos academicos.
  • ADR-009: CI/CD orientado a AWS (ECS + S3/CloudFront).
